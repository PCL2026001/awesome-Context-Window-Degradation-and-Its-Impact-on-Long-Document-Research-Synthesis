# Tools and Libraries

This file lists major frameworks, libraries, and software used in long-context LLM research.

---

## Hugging Face Transformers

Purpose:

State-of-the-art pretrained language models.

Applications:

- Long-context models.
- Fine-tuning.
- Inference.

---

## LangChain

Purpose:

Framework for building LLM applications.

Supports:

- RAG.
- Agents.
- Prompt templates.
- Vector databases.

---

## LlamaIndex

Purpose:

Indexing and querying long document collections.

Features:

- Document chunking.
- Hierarchical retrieval.
- Citation tracking.

---

## Haystack

Purpose:

Open-source retrieval pipeline.

Supports:

- BM25.
- Dense retrieval.
- Hybrid search.
- Question answering.

---

## Sentence Transformers

Purpose:

Semantic embeddings.

Applications:

- Similarity search.
- Document retrieval.
- Clustering.

---

## FAISS

Purpose:

Efficient similarity search for embeddings.

---

## FlashAttention

Purpose:

Memory-efficient Transformer attention.

Useful for long sequences.

---

## vLLM

Purpose:

Fast inference engine for LLMs.

Supports efficient KV cache and long-context inference.

---

## Summary

| Tool | Primary Use |
|------|--------------|
| Transformers | Model loading and fine-tuning |
| LangChain | RAG pipelines |
| LlamaIndex | Document indexing |
| Haystack | Retrieval pipelines |
| Sentence Transformers | Embeddings |
| FAISS | Vector search |
| FlashAttention | Efficient attention |
| vLLM | High-performance inference |

---

## Why These Tools Are Included

These tools represent the most commonly used ecosystem for implementing long-context retrieval, synthesis, and evidence-grounded language model applications.
